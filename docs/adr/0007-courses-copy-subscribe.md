# Courses: copy-on-subscribe with Card-local scheduling

Courses are Course-owned Decks/Cards. Subscribe copies Cards into one flattened Deck in the User's private space (home Courses section), keeping scheduling on each copy. Source links enable living content sync, Review snapshots for diffs, skip/retire, and unsubscribe keep-or-delete. This continues ADR 0006 (no shared Card + separate progress table).
