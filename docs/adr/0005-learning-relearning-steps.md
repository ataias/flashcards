# Hybrid Learning / Relearning steps + unfloored FSRS Review

We want Again-in-minutes without abandoning FSRS for long-term scheduling. v1.2 uses Anki-like phases (New → Learning → Review; Again on Review → Relearning → Review) with hard-coded steps (Learning `1m 10m`, Relearning `10m`) and Anki-like button behavior. FSRS Again applies immediately on Review lapse; steps only delay the next due. Review intervals use unfloored FSRS (no ≥1 day floor). Settings UI and a separate learn-mode Study UI are deferred.
